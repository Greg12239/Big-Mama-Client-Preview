# Big Mama Burgers n' Fries

Premium static landing page for the Big Mama burger brand.

## Project Structure

- `index.html` is the production entry file.
- `styles.css` contains the responsive visual system and motion styling.
- `app.js` handles loading, reveal animations, scroll progress, mobile navigation, and scroll motion.
- `public/assets/` contains all production images and brand assets.

## Deploy To GitHub Pages

1. Create a new GitHub repository.
2. Upload the full contents of this folder to the repository root.
3. In GitHub, open `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and `/root` folder.
6. Save. GitHub will publish the site from `index.html`.

The site is static and does not require a build step.
